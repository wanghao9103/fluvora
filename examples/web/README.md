# Browser SDK demo

This is a no-framework, runnable integration of `@fluvora/web`. It supports:

- SFU publishing/subscribing with camera and microphone;
- P2P offer/answer/ICE signaling between two browser tabs;
- reliable room DataChannel messages and durable chat/custom commands;
- WebRTC network samples, automatic sender bitrate adaptation and HLS fallback;
- direct live/VOD HLS manifest playback when the browser supports the manifest.

Build the SDK, then serve the repository root (camera access requires localhost or HTTPS):

```bash
cd sdk/web
npm ci
npm run build
cd ../..
python -m http.server 3000
```

Open `http://127.0.0.1:3000/examples/web/`. The Compose example allows this origin by default; for
another port, add its exact origin to `FLUVORA_CORS_ORIGINS`. Paste a short-lived user token generated by the
deployment's identity service; the demo never persists the token. For P2P, open two tabs with
tokens whose `sub` values identify different participants, join the same P2P room, start each peer,
and enter the other participant's ID before sending an offer. The UI decodes `sub` only as a
convenience; the server still authenticates and verifies the token.
